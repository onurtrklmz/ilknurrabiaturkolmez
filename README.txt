İLKNUR RABİA TÜRKÖLMEZ — AKADEMİK PORTFOLYO

1) DOSYA
- index.html tek başına çalışır.
- Tarayıcıda çift tıklayarak önizleyebilirsiniz.
- Harici bağımlılık yalnızca Google Fonts'tur. Font yüklenmezse sistem fontlarıyla çalışır.

2) ANA GÖRSEL
- Profil fotoğrafı yerine “Yargısal Tutum” kitabının kapak görseli doğrudan index.html içine gömülmüştür.
- Görsel ayrıca bir dosya olarak taşınmak zorunda değildir; HTML tek başına çalışır.

3) GOOGLE SITES'A EKLEME
Google Sites tam bir özel HTML/CSS temasını doğrudan site şablonu olarak çalıştırmaz.
En temiz yöntem:

A) index.html dosyasını GitHub Pages veya Cloudflare Pages üzerinde yayınlayın.
B) Google Sites > Ekle > Yerleştir > URL yolunu izleyin.
C) Yayınlanan sayfanın URL'sini girin.
D) Gömülü alanı sayfa genişliğine ve uygun yüksekliğe getirin.

4) GİTHUB PAGES İÇİN KISA YOL
- Yeni bir repository açın.
- index.html ve profil.jpg dosyasını yükleyin.
- Settings > Pages > Deploy from branch seçin.
- main / root seçin.
- Oluşan URL'yi Google Sites'a gömün.

5) NOT
CV'de yer alan cep telefonu numarası kamusal web sayfasına özellikle eklenmemiştir.
İsterseniz iletişim bölümüne sonradan eklenebilir.


FAVICON
- favicon.svg: ana vektör favicon
- favicon.ico: klasik tarayıcı uyumluluğu
- favicon-32x32.png ve favicon-16x16.png: küçük tarayıcı ikonları
- favicon-192x192.png / favicon-512x512.png: yüksek çözünürlüklü ikonlar
- index.html içine gerekli <link rel="icon"> satırları eklenmiştir.


YÖK FORMATINDA TAM CV

- GitHub Pages / Cloudflare Pages kullanırken PDF dosyasını index.html ile aynı dizinde tutun.
